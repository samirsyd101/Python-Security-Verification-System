# Python-Security-Verification-System
Python project that demonstrates password verification, basic encryption, decryption, and access control

## About the Project

I created this project to practice and further strengthen my Python programming skills while learning more about basic cybersecurity concepts. The program allows users create a password, verify the password, encrypt information by utilizing simple character shifting technique, and decryption of information only after the correct password has been entered by the user. 

## Features
- Creation and verification of password
- Simple encryption and decryption
- Password-based access control
- Error message for wrong passwords.


## Technologies used
- Visual Studio Code
- Python 3

## What I Learned

This project has helped me grasp a better understanding of Python loops, conditional statements, and manipulation of strings. I was also able to have hands-on experience with simple security concepts such as password verification and access control. 

## Security Note
Purpose of this project was for educational purposes, and it utilizes a basic character shifting technique instead of secure encryption.
